# Student Helper Bot — ВГУ

Telegram-бот помощника студента ВГУ (факультет КН) с интеграцией WebApp.

## Функционал

- **Многопользовательская поддержка** — каждый студент авторизуется под своими данными от cs.vsu.ru прямо в приложении.
- **Оценки из БРС** — автоматический парсинг таблицы успеваемости, расчет процентов посещаемости.
- **Расписание** — удобный просмотр пар с фильтрацией по курсу, группе и подгруппам (числитель/знаменатель).
- **Фоновый мониторинг БРС** — бот сам раз в час проверяет оценки и присылает Push-уведомление в Telegram, если преподаватель поставил новую оценку.
- **Напоминания о парах** — за 15 минут (настраивается) до начала пары бот пришлет напоминание.
- **Калькулятор посещаемости** — симуляция влияния пропусков на итоговый балл.
- **Задачник** — простой ToDo-лист прямо на главном экране WebApp.

## Технологии

- **Бэкенд:** Python, FastAPI, aiogram 3.x
- **База данных:** SQLite (aiosqlite) + SQLAlchemy 2.0 (async)
- **Парсер:** httpx, BeautifulSoup4
- **Фронтенд:** HTML/CSS/JS (Telegram WebApp, без фреймворков, "vanilla")
- **Туннелирование:** ngrok / cloudflared (настраивается через `launch.py`)

## Установка

```bash
git clone <repo>
cd student-helper-bot
python -m venv .venv
.venv\Scripts\activate      # Windows
pip install -r requirements.txt
```

## Настройка (.env)

Скопируй `.env.example` в `.env` и заполни только необходимое:

```env
BOT_TOKEN=123456:ABC-DEF1234ghIkl-zyx57W2v1u123ew11 # токен от @BotFather
API_PORT=8000
```

*(Логины и пароли БРС теперь настраиваются самими пользователями через интерфейс приложения, в .env их прописывать не нужно).*

## Запуск

В проекте настроен удобный автозапуск для Windows:

```cmd
start.bat
```
Что делает скрипт:
1. Запускает `launch.py`.
2. Автоматически поднимает `ngrok` туннель для работы WebApp.
3. Прокидывает публичный URL в переменные окружения.
4. Поднимает FastAPI сервер и aiogram-бота в фоне.
5. Автоматически перезапускает бота в случае падения.

## Структура проекта

```
main.py                  # точка входа (запуск uvicorn, aiogram, фоновых задач)
launch.py                # скрипт запуска с ngrok
api/                     # FastAPI сервер (эндпоинты для WebApp)
bot/                     # логика Telegram бота (хендлеры, клава)
database/                # Async SQLAlchemy (модели, сессии)
utils/                   # парсеры (БРС, расписание), калькуляторы
webapp/                  # исходники фронтенда (HTML/JS/CSS)
```
