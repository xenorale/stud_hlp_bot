# Student Helper Bot

Ваш личный помощник для учебы в ВГУ. Бот помогает следить за расписанием, получать уведомления о парах и отслеживать оценки БРС.

## Как начать работу
1. Перейдите по ссылке: [@stud_hlp_bot](https://t.me/stud_hlp_bot).
2. Нажмите кнопку **Start**.
3. Следуйте инструкциям бота для настройки профиля (курс, группа, подгруппа).

## Основные возможности

### 🕒 Расписание
* Бот автоматически определяет текущую неделю (числитель/знаменатель).
* Получайте актуальное расписание пар для вашей группы.
* Можно настроить **уведомления** перед началом пары, чтобы не пропустить занятие.

### 📊 БРС (Балльно-рейтинговая система)
* Мониторинг успеваемости: бот пришлет уведомление, как только в БРС появится или изменится оценка.
* Автоматическая синхронизация с вашим личным кабинетом.

---
*Бот работает централизованно. Все данные передаются в зашифрованном виде.*
